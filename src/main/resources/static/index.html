Добавить узел

Шаг 1 из 2
Это режим переустановки. Имя узла уже подставлено — после установки агент по нему найдёт существующий узел и переиспользует его id (метрики и алерты не потеряются).
Linux (systemd)
Windows
Команда установки создаёт системный сервис с автозапуском при загрузке узла и автоматическим перезапуском при падении агента. Нужны права sudo (Linux) / Administrator (Windows). После установки никаких ручных действий на узле больше не требуется.
Через ~10 секунд узел появится в списке. После установки агент запускается как сервис: переживёт reboot, авто-рестарт при падении, ручной запуск больше не нужен.
Управление токенами (продвинутый режим)
Здесь видны agent-токены, выпущенные для твоих узлов. Обычно сюда заходить не нужно — токены автоматически отзываются, когда выпускается новый. Используй, если хочешь принудительно отозвать токен (например, узел украли).

Откуда придёт письмо? С того адреса, который вы укажете в «Email From», а доставляться оно будет через тот SMTP-сервер и логин/пароль, что заданы выше. Пример: для Яндекса — host smtp.yandex.ru, port 587, username = ваш ящик, password = пароль приложения; для mail.ru — smtp.mail.ru + аналогичный пароль приложения; для Gmail — smtp.gmail.com + app password.
